Ресурсы проекта Forest Ranger

На этой странице собраны все ключевые материалы, связанные с разработкой игры: от исходного кода до документации используемых фреймворков.

📂 Основные ссылки

  • GitHub Репозиторий — основной исходный код (Unity Project).
  • Telegram-канал «Почти Singleton» — блог о ходе разработки и технических инсайтах проекта.

🛠 Технологический стек (Architecture & Tools)

Мы используем современный стек для Unity, который позволяет строить масштабируемую и производительную архитектуру.

💉 Dependency Injection & Architecture

Инструмент Описание Ссылка
Extenject (Zenject) Фреймворк для реализации паттерна DI. Обеспечивает слабую связанность систем. Документация

⚡ Async & Reactive

Инструмент Описание Ссылка
R3 (Reactive Extensions) Основа событийной модели игры. Позволяет элегантно обрабатывать ввод и логику мира. GitHub R3
UniTask Оптимизированная библиотека для работы с асинхронностью без лишних аллокаций. GitHub UniTask

🎨 Visual & Tweening

Инструмент Описание Ссылка
DOTween Движок анимаций. Используется для UI, переходов и процедурного движения объектов. Официальный сайт

📚 Рекомендуемые материалы

Для глубокого понимания архитектуры нашего проекта рекомендуем ознакомиться со следующими ресурсами:

  1. Паттерны проектирования в Unity — лучшие практики применения DI и SOLID.
  2. Асинхронное программирование — почему UniTask лучше стандартных Coroutines.
  3. Событийно-ориентированная логика — основы реактивного подхода в геймдеве.

🏛 Партнеры и организация

Проект реализуется при поддержке Московского Политеха в рамках программы проектной деятельности студентов.
