## 🛠 Технологический стек (Architecture & Tools)

Мы используем современный стек для Unity, который позволяет строить масштабируемую и производительную архитектуру.

### 💉 Dependency Injection & Architecture
| Инструмент | Описание | Ссылка |
| :--- | :--- | :--- |
| **Extenject (Zenject)** | Фреймворк для реализации паттерна DI. Обеспечивает слабую связанность систем. | [Документация](https://github.com/svermeulen/Extenject) |

### ⚡ Async & Reactive
| Инструмент | Описание | Ссылка |
| :--- | :--- | :--- |
| **R3 (Reactive Extensions)** | Основа событийной модели игры. Позволяет элегантно обрабатывать ввод и логику мира. | [GitHub R3](https://github.com/Cysharp/R3) |
| **UniTask** | Оптимизированная библиотека для работы с асинхронностью без лишних аллокаций. | [GitHub UniTask](https://github.com/Cysharp/UniTask) |

### 🎨 Visual & Tweening
| Инструмент | Описание | Ссылка |
| :--- | :--- | :--- |
| **DOTween** | Движок анимаций. Используется для UI, переходов и процедурного движения объектов. | [Официальный сайт](http://dotween.demigiant.com/) |

## 📚 Рекомендуемые материалы
Для глубокого понимания архитектуры нашего проекта рекомендуем ознакомиться со следующими ресурсами:
1.  **Паттерны проектирования в Unity** — лучшие практики применения DI и SOLID.
2.  **Асинхронное программирование** — почему `UniTask` лучше стандартных `Coroutines`.
3.  **Событийно-ориентированная логика** — основы реактивного подхода в геймдеве.
