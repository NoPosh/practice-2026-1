## Ссылки на проект
*   **Репозиторий проекта:** [GitHub / Forest Ranger](https://github.com/NoPosh/ForestRangerGame.git) — основной исходный код игры.

## Технологический стек (Unity & C#)
Для реализации архитектуры в проекте используются следующие инструменты:
*   **R3 (Reactive Extensions for .NET):** [GitHub R3](https://github.com/Cysharp/R3) — основа для событийной модели игры.
*   **UniTask:** [GitHub UniTask](https://github.com/Cysharp/UniTask) — библиотека для эффективной асинхронности в Unity.
*   **Extenject (Zenject):** [Документация Zenject](https://github.com/svermeulen/Extenject) — Dependency Injection фреймворк для слабой связанности систем.
*   **DOTween:** [Официальный сайт](http://dotween.demigiant.com/) — движок для создания плавных анимаций через код.
